Building an agent

Making it say "I don't know"

  you: "who won the 2031 world cup?"
        │
        ▼
  ┌──────────────────────┐
  │ guess the next word  │
  └──────────────────────┘
        │
        ▼
  "The winning team was the ..."
        ↑
  it kept going. guessing is the only
  setting it has.

It can't decline to answer — a guess is all it can produce. So it invents a team, a score, a date, in fluent prose. The confidence is real; the accuracy isn't.

You fix this outside the model: tell it plainly in the system prompt — "if you're not sure, say you don't know instead of guessing" — and give it a tool to check facts when one exists.

It won't be perfect. But the fallback flips from silent invention to an actual sentence you can build on.
