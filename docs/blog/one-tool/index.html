Building an agent

Give your agent one tool

  you: "what files are in ~/notes?"
        │
        ▼
  ┌──────────────────────┐
  │ guess the next word  │
  └──────────────────────┘
        │
        ▼
  {"tool": "list_files", "path": "~/notes"}
        │          ← it cannot run this.
        ▼             it just wrote it down.
  your code: runs the real thing,
             pastes the output back in
        │
        ▼
  "You have 3 files: a.md, b.md, c.md"

That's the whole invention: the model is the decider, your code is the hands. It never touches a file, a network, a key — it writes down what should happen.

The loop, once it has a tool: reason → ask for a tool call → your code runs it → paste the result back → reason again. Cap the loop (say, 10 steps) or a confused model can spin forever.

One tool changes everything. It goes from a thing that talks about your files to a thing that can look at them.
