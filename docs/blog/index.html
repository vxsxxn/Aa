Notes from building an AI agent.

Give your agent one tool

The model decides. Your code acts.

  model: "call list_files"
  your code runs it → paste result back
Why your agent calls the wrong tool

Vague descriptions are the #1 cause.

  "gets the weather"
  → get_weather(city="Paris, TX")
     right name, wrong place
Why your agent forgets

The context window is a slot, not a mind.

  whiteboard fills up
  → oldest turns fall off
  "what did I say first?" — gone
Making your agent say "I don't know"

A guesser never stops to say dunno.

  "who won the 2031 cup?"
  guess → "The winner was ..."
  it never had a "dunno" setting
Your agent got dumb after you pasted a PDF

Long inputs crowd out attention — and bill.

  50-page PDF pasted in
  → every later word competes
     with 50 pages
Memory: retrieve, don't store

Save notes, pull back what matters.

  store everything → slow, bloated
  retrieve 2 relevant bits → paste in
Framework or no framework

Call the API directly once.

  framework: hides the loop
  no framework: 20 lines, all visible
Money and keys

Keys live in env vars. Set a cap on day one.

  key in client code → leaked
  env var on your server → safe
