Building an agent

Memory: retrieve, don't store

  store everything:
    chat log grows → re-read ALL of it
    every turn → slow, bloated, dumb
        vs
  retrieve:
    "what does this turn need?"
        │
        ▼
    pull the 2 relevant bits
        │
        ▼
    paste just those in

A memory that replays everything is just the whiteboard problem again, on a delay: it fills, it's slow, the old noise drowns the new signal.

The useful version is a lookup: save notes as they happen, and on each turn retrieve only what's relevant — a search over your notes, results pasted into the window.

Rule of thumb: the window holds a moment, not a life story. Memory is what you do about that.
