Building an agent

Your agent got dumb after you pasted a PDF

  paste a 50-page PDF into the chat
        │
        ▼
  every later word now competes
  with 50 pages of text
        │
        ▼
  small stuff gets worse —
  it misses things it caught before

The model doesn't "read" your paste and file it away. The whole thing sits in the window, and attention gets spread across all of it. Instructions that worked in a 2-page chat quietly fail in a 60-page one.

It also bills by the token — a fat paste makes every later turn expensive, not just the one you pasted it into.

Builder takeaway: don't dump documents in. Extract what the question needs and paste only that. Smaller context = sharper model, cheaper bill.
