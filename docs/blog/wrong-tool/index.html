Building an agent

Why your agent calls the wrong tool

  your tool:
      get_weather(city)
      "gets the weather"
        │
        ▼
  you: "is it warm in Paris?"
        │
        ▼
  get_weather(city="Paris, Texas")
                  ↑
         right name, wrong place

The model only knows what the description tells it. "Gets the weather" doesn't say which Paris. The description isn't a comment — it's the manual the model reads before every call.

Fix it by writing for a confused intern: say what it does, what it takes, and what not to use it for. "Current weather by city name. Use the full city and country. Not for forecasts — use get_forecast for that."

Same for the arguments: name them what they are. city, not q. The model fills in what it can read.
