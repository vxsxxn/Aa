Aa

A desktop AI agent you stay in charge of.

What it is

Aa is a desktop AI agent for building things — code, sites, and day-to-day work. It started as a fork of Hermes Agent and is becoming its own project.

How it works

  • You stay in charge Every action needs your approval before it runs.
  • No lock-in Your data stays portable and open. Leave whenever you want.
  • Free will Aa helps; it doesn’t take the wheel.

What’s in it

  • Desktop settings Configure the agent on your machine.
  • Approvals UI Review and allow actions before they happen.
  • Secret vault Keep credentials out of plain files and chat.
  • Mods system Extend Aa without rewriting the core.

Install

From the repo, with Python 3.11–3.14:

git clone https://github.com/vxsxxn/Aa.git
cd Aa
pip install -e .
Aa

The CLI entry point is Aa.
