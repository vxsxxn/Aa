FAQ

Common questions

What is Aa?

Another alternative AI agent: software that runs on your computer and does tasks for you. There are a lot of these, and Aa is one more. It started from Hermes Agent by Nous Research so it did not have to be built from scratch, and it is its own project.

How do I install it?

Clone the repo, run pip install -e ., then start with Aa. Needs Python 3.11–3.14.

Is it open source?

Yes. MIT License. Based on Hermes Agent by Nous Research — keep the credit.
