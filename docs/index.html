What is Aa?

A desktop AI agent for building things — code, sites, and day-to-day work. It is a fork of Hermes Agent by Nous Research and is becoming its own project.

How do I install it?

Clone the repo, run pip install -e ., then start with Aa. Needs Python 3.11–3.14.
